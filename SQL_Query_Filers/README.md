# SQL Query Filters for Security Investigations

## Overview

This project demonstrates the use of SQL filters to investigate potential security incidents and identify employee machines requiring security updates.

The analysis uses data from the `log_in_attempts` and `employees` tables. SQL operators and keywords—including `AND`, `OR`, `NOT`, and `LIKE`—were used to retrieve records that matched specific security and operational requirements.

## Key Security Focus

* Login activity investigation
* Failed authentication analysis
* Date and time filtering
* Geographic login analysis
* Employee device identification
* Targeted security updates
* Pattern matching in database records

## Skills Demonstrated

* Writing SQL `SELECT` statements
* Filtering records with `WHERE`
* Combining conditions with `AND` and `OR`
* Excluding records with `NOT`
* Searching for patterns with `LIKE`
* Using the `%` wildcard
* Filtering date and time values
* Querying multiple database tables
* Documenting security investigations
