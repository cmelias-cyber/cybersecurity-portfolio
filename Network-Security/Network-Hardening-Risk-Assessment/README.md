# Network Hardening Risk Assessment

## Overview
This project analyzes multiple network security vulnerabilities identified after a data breach at a social media organization. The assessment focuses on evaluating weak security practices, identifying risks to the organization’s network and customer data, and recommending network hardening measures to strengthen overall security.

The project applies foundational cybersecurity concepts related to password security, firewall management, multifactor authentication (MFA), and network access control to reduce the likelihood of future attacks and unauthorized access.
