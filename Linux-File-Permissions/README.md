# Linux File Permissions Management

## Overview

This project demonstrates the use of Linux commands to examine and modify file and directory permissions in a research environment.

The goal of the project was to ensure that users had only the access required for their roles. Existing permissions were reviewed and updated to remove unauthorized write access, protect an archived hidden file, and restrict access to a sensitive directory.

## Key Security Focus

* File and directory permissions
* User, group, and other authorization
* Principle of least privilege
* Removal of unauthorized access
* Protection of hidden files
* Secure directory access

## Skills Demonstrated

* Inspecting permissions with `ls -la`
* Interpreting Linux permission strings
* Modifying permissions with `chmod`
* Managing hidden files
* Restricting directory access
* Applying access-control requirements
* Documenting security changes
