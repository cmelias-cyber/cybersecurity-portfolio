# ICMP DoS Incident Response Analysis

## Overview
This project analyzes a distributed denial-of-service (DDoS) incident targeting a multimedia organization. The attack leveraged ICMP traffic to overwhelm internal network services, resulting in a temporary outage and disruption of critical business operations.

The investigation applies the NIST Cybersecurity Framework (CSF) to assess the incident lifecycle, including identification of the attack vector, protective controls, detection mechanisms, incident response actions, and system recovery procedures.

This project demonstrates practical skills in network traffic analysis, firewall-based mitigation strategies, and incident response planning.

---

## Skills Demonstrated
- Network traffic analysis (tcpdump interpretation)
- ICMP-based DoS attack investigation
- NIST Cybersecurity Framework (CSF) application
- Firewall rule analysis and mitigation strategies
- Intrusion detection concepts (IDS/IPS)
- Incident response documentation
- Security hardening and monitoring strategies
