# Network Traffic Analysis: DNS and ICMP Incident

## Overview

This project analyzes network traffic using tcpdump to investigate a service disruption affecting access to the website **yummyrecipesforme.com**. The analysis focuses on DNS (UDP) and ICMP traffic to identify the root cause of the issue.

The objective is to determine which network protocol and service were impacted and interpret error messages observed in packet data.

---

## Key Focus Areas

- DNS protocol behavior (UDP port 53)
- ICMP error message analysis
- UDP communication issues
- Packet-level log interpretation using tcpdump
- Network service failure identification

---

## Skills Demonstrated

- Network traffic analysis
- Log interpretation (tcpdump)
- DNS and ICMP protocol analysis
- Identifying service disruptions
- Basic incident response documentation
