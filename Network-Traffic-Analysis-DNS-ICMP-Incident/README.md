# Network Traffic Analysis: DNS and ICMP Incident

## Overview

This project analyzes network traffic using tcpdump to investigate a service disruption affecting access to a website. The analysis focuses on DNS and ICMP traffic to identify the root cause of the issue.

The objective is to determine which network protocol and service were impacted and interpret error messages observed in packet data.

---

## Key Focus Areas

* DNS protocol behavior
* ICMP error message analysis
* UDP communication issues
* Port-level troubleshooting (Port 53)
* Network traffic interpretation using tcpdump

---

## Skills Demonstrated

* Network traffic analysis
* Log interpretation (tcpdump)
* Protocol analysis (DNS, ICMP, UDP)
* Identifying service disruptions
* Cybersecurity incident reporting
